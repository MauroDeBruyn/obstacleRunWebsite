## 🧭 About <a name="about"></a>

Desert Fire Run Website is a static website built for a local obstacle running competition to centralize all practical event information in one place.  
It provides participants with clear details about registrations, heats, location, rules, and the charity cause behind the event (Wensambulance), while being easy to maintain by the organizers.  

Live site: [**https://desertfirerun.hvznl.be**](https://desertfirerun.hvznl.be)

---

## 🚀 Features <a name="features"></a>

- ✨ Event overview section with date, location, and concept of the obstacle run.  
- 💸 Information about registration, pricing, and where to sign up or donate.  
- ❤️ Highlight of the charity goal (Wensambulance) and why the run supports it.  
- 🧱 Practical info for runners: obstacles, preparation tips, and what to bring.  
- 📍 Clear structure suitable for mobile and desktop visitors.

## ⚙️ Installation <a name="installation"></a>

```bash
# Clone this repository
git clone https://github.com/MauroDeBruyn/desertFireRunWebsite.git

# Navigate into the project folder
cd desertFireRunWebsite

# Since this is a static HTML/CSS site, no build or runtime dependencies are required.
# You can open the site directly via index.html or serve it with any static server.

# Option 1: open directly
# Double-click index.html or open it in your browser.

# Option 2: use a simple dev server (example with Python 3)
python -m http.server 8000

# Then visit
http://localhost:8000
```

## 🧱 Tech Stack <a name="techstack"></a>

- **HTML5** – structure and content of all pages.  
- **CSS3** – layout, colors, typography, and responsive behavior.  

There are no external build tools, frameworks, or backend services required.
